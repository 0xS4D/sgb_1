# SGB — Sistema de Gestión de Bibliotecas

Instalador para Windows de la versión **3.1.1**.

## Descargar

**[Descargar SGB-3.1.1-Setup.exe](https://github.com/0xS4D/sgb_1/raw/main/SGB-3.1.1-Setup.exe)** (57 MB)

## Instalar

1. Ejecutá `SGB-3.1.1-Setup.exe` y seguí los pasos.
2. Si a la PC le falta .NET Framework 4.0, el instalador lo agrega solo; no hace falta internet.
3. Al terminar, abrí SGB desde el escritorio o el menú Inicio.

Si ya tenés SGB instalado, instalá esta versión encima. Los datos se conservan.

Funciona en Windows XP SP3, Vista, 7, 8, 10 y 11.

## Novedades de la 3.1.1

- Si la web no acepta un cambio, la PC lo vuelve a mandar sola y en Ajustes explica qué pasó y qué hacer.
- Si una PC tiene la fecha y hora mal, el programa avisa cuál es y, cuando se corrige, sus cambios vuelven a circular.
- Una PC con Windows XP dice claramente si puede conectarse con la web y si otra PC de la red sube sus cambios.

## Ayuda

Dentro del programa, el botón **Ayuda (F1)** abre la guía de uso.
