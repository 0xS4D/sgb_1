# SGB — Sistema de Gestión de Bibliotecas

Instalador para Windows de la versión **3.1.2**.

## Descargar

**[Descargar SGB-3.1.2-Setup.exe](https://github.com/0xS4D/sgb_1/raw/main/SGB-3.1.2-Setup.exe)** (59 MB)

## Instalar

1. Ejecutá `SGB-3.1.2-Setup.exe` y seguí los pasos.
2. Si a la PC le falta .NET Framework 4.0, el instalador lo agrega solo; no hace falta internet.
3. Al terminar, abrí SGB desde el escritorio o el menú Inicio.

Si ya tenés SGB instalado, instalá esta versión encima. Los datos se conservan.

Funciona en Windows XP SP3, Vista, 7, 8, 10 y 11.

## Novedades de la 3.1.2

- Las PCs con Windows 7 o Windows XP ya pueden conectarse con la web: si la conexión segura de Windows no alcanza, SGB usa la suya.
- Un administrador puede eliminar una obra o un ejemplar cargados por error desde la ficha de la obra. Lo que ya tuvo préstamos o incidencias se saca con «Baja», así la historia no se pierde.
- Se corrigió el error que aparecía con la pantalla de ingreso minimizada. Un error inesperado ahora muestra un aviso corto en castellano.

## Ayuda

Dentro del programa, el botón **Ayuda (F1)** abre la guía de uso.
